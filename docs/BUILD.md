# Запуск и сборка приложения

## Windows: просто запустить

1. Установите **Python 3.10+**. В установщике отметьте **Add Python to PATH**.
2. Распакуйте/клонируйте репозиторий в обычную папку с правом записи.
3. Дважды щёлкните **`start.bat`**.

При первом запуске скрипт создаст `.venv` и установит зависимости через pip.
Нужен интернет. Следующие запуски используют это окружение без повторной установки,
если pygame-ce уже установлен. Активация PowerShell не нужна.

Для запуска из терминала:

```bat
start.bat
start.bat --check
start.bat --mute
```

Скрипт сам переходит в папку проекта. `python main.py` тоже находит `game/`
рядом с исходниками независимо от рабочей папки терминала.
`python -m bne` по-прежнему ищет `game/` в текущей рабочей папке либо принимает явный путь.

## Windows: собрать `.exe`

Дважды щёлкните **`build.bat`**. На компьютере сборщика нужны Python, интернет
для установки зависимостей и место для сборки. Администраторские права не нужны.

Скрипт установит PyInstaller, проверит сценарии и соберёт приложение:

```text
dist/
├── BerlNovellaEngine/
│   ├── BerlNovellaEngine.exe   # запуск двойным кликом, без консоли
│   ├── _internal/             # Python, pygame-ce и нативные библиотеки
│   ├── game/                  # manager.bne, сцены, изображения, звук, шрифт
│   ├── licenses/              # лицензии компонентов
│   ├── LICENSE
│   ├── README.txt
│   └── bne-build.json
└── BerlNovellaEngine-windows-x86_64.zip
```

Название архитектуры в архиве зависит от Python/компьютера сборщика.
**На компьютере игрока Python не нужен.** Передавайте ZIP целиком.
Игрок должен сначала распаковать весь архив, а потом открыть `.exe`.
Нельзя переносить один `.exe` без папок `_internal/` и `game/`.

Это упаковка Python-приложения вместе с интерпретатором и библиотеками,
а не перевод сценариев в машинный код. `.bne` остаются редактируемыми:
диалоги и ресурсы в готовой папке игры можно менять без пересборки движка.
Для изменения самого Python-движка нужна новая сборка.

Сборка не подписана цифровой подписью. Windows может показать предупреждение
о неизвестном издателе; это не заменяет проверку происхождения файла.

### Повторная сборка

По умолчанию существующий результат не затирается. Чтобы заменить именно
предыдущую сборку BNE:

```bat
build.bat --overwrite
```

**Перед заменой скопируйте нужные сохранения из старой `dist/.../game/saves/`.**
Старая сборка, в том числе её сохранения и отредактированные сцены, будет заменена.
Исходная папка `game/` не изменяется. Авторские сохранения из исходников,
скрытые файлы и кэши в релиз не копируются.

Новая сборка сначала готовится во временной папке и проверяется запуском
готового приложения с `--check` из чужой рабочей папки. Только после этого
она заменяет предыдущую. Произвольную папку без маркера сборки скрипт не удаляет.

### Если приложение не открывается

Для оконного Windows-приложения ошибки запуска сохраняются в:

```text
%LOCALAPPDATA%\BerlNovellaEngine\last-run.log
```

Если запись туда невозможна, используется `%TEMP%\BNE\last-run.log`.
Ожидаемая ошибка запуска также показывается системным окном.
Ключ `--check` возвращает ненулевой код ошибки, но не открывает модальное окно.
В запущенной игре ошибки сценария по-прежнему отображаются самим движком.

Распакуйте игру в доступную для записи папку, например в пользовательские
«Документы», а не в защищённую `Program Files`. Сохранения по умолчанию лежат
в `game/saves/`. Для другой папки передайте `--save-dir` через терминал/ярлык.

## Сборка командой на Windows / Linux / macOS

В активированном окружении из корня репозитория:

```bash
python -m pip install -e ".[build]"
python tools/build.py
```

На Windows этот вариант эквивалентен `build.bat`, но без вспомогательной
подготовки окружения. Для Linux/macOS результат — папка с нативным исполняемым
файлом `BerlNovellaEngine`, не `.exe`. Для macOS пока не создаются `.app`,
подпись или notarization; запускать бинарник можно из Terminal.

```bash
./dist/BerlNovellaEngine/BerlNovellaEngine
./dist/BerlNovellaEngine/BerlNovellaEngine --check
```

Если программа распаковки потеряла Unix-права запуска, восстановите их:

```bash
chmod +x dist/BerlNovellaEngine/BerlNovellaEngine
```

Параметры сборщика:

```bash
python tools/build.py --game path/to/game --name MyNovel
python tools/build.py --output path/to/releases
python tools/build.py --overwrite
```

`--game` принимает папку с `manager.bne`. Все используемые ресурсы должны
быть обычными файлами: при упаковке символические ссылки намеренно запрещены.
Собственная игра должна использовать поддерживаемый синтаксис BNE 0.1.

**PyInstaller не выполняет кросс-компиляцию:** `.exe` собирается на Windows,
Linux-бинарник — на Linux, macOS-бинарник — на Mac. Разрядность тоже зависит
от выбранного Python. Linux-сборки могут зависеть от версии glibc; для широкой
совместимости собирайте на самой старой из поддерживаемых вами систем.

Если Linux сообщает о недостающей `libpython3.x.so`, установите пакет общей
библиотеки именно вашей версии Python через пакетный менеджер системы либо
используйте обычную установку Python с shared library. Сборщик не скачивает
и не подменяет системный Python автоматически.

Сборки в `dist/` и промежуточные файлы не попадают в Git. PyInstaller и
зависимости сборки устанавливаются только через extra `.[build]`.
Для воспроизводимого набора уведомлений о лицензиях он фиксирует pygame-ce 2.5.8.
Перед публичным релизом проверьте также лицензии всех своих ресурсов,
плагинов и нативных библиотек целевой платформы.
