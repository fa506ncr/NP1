# Язык `.bne` · версия 0.1

Синтаксис вдохновлён Ren’Py, но это отдельный язык Berl Novella Engine,
**не совместимый со всеми возможностями `.rpy`**.

## Общие правила

- Файлы в UTF-8, расширение `.bne`. UTF-8 BOM тоже принимается.
- Один оператор на строку. Многострочные строковые литералы не поддерживаются.
- Один уровень вложенности — **4 пробела**. Табуляция в отступах запрещена.
- Комментарий начинается с `#` вне кавычек. Пустые строки игнорируются.
- Имена переменных, персонажей, сцен и меток: латиница, цифры и `_`,
  первый символ — буква. Ключевые слова Python не подходят для имён.
- Строки в одинарных или двойных кавычках; поддерживаются `\n`, `\"` и `\\`.
- Произвольные вызовы Python, импорты, атрибуты и выполнение кода запрещены.
- Все ресурсы и сценарии должны лежать **внутри папки игры**.

## 1. `manager.bne`

Главный файл содержит объявления без отступов. Команды диалогов в нём не пишутся.

### Настройки

```renpy
define config.title = "Название игры"
define config.width = 1280
define config.height = 720
define config.text_speed = 42
define config.music_volume = 0.35
define config.font = "gui/DejaVuSans.ttf"
```

| Настройка | По умолчанию | Значение |
| --- | --- | --- |
| `title` | `"Berl Novella Engine"` | 1–120 символов |
| `width` | `1280` | Целое 640–3840; логическая ширина отрисовки |
| `height` | `720` | Целое 360–2160; логическая высота отрисовки |
| `text_speed` | `42` | 0–200 символов/с; `0` — мгновенно |
| `music_volume` | `0.35` | 0–1; громкость музыки без явного `volume` |
| `font` | шрифт pygame | Относительный путь к шрифту; для кириллицы лучше комплектный DejaVu Sans |

Физическое окно можно менять в размере; холст масштабируется с полями,
если пропорции окна отличаются. Одинаковую настройку нельзя объявлять дважды.

### Персонажи

```renpy
define m = Character("Мира", color="#9EE4D2")
define p = Character("[player_name]", color="#EBC99A")
define n = Character(None)
```

`color` необязателен: по умолчанию `#B8D9E8`. Формат цвета — `#RRGGBB`.
`None` скрывает имя рассказчика. Имя с подстановками вычисляется перед каждой
репликой и не должно превышать 100 символов. Идентификатор персонажа не может
совпадать с командой вроде `show` или `jump`.

### Переменные

```renpy
default player_name = "Гость"
default trust = 0
default has_key = False
default extra_trust = trust + 1
```

Новая игра получает свежие значения. Объявления `default` вычисляются сверху вниз:
можно ссылаться на уже объявленные переменные. Дальше менять переменные нужно
через `$` в сценарии. Необъявленные имена считаются ошибками, чтобы ловить опечатки.

Типы: строка, целое, дробное число, `True`, `False`, `None`.
Списков, словарей, объектов и пользовательских функций пока нет.

### Изображения

```renpy
image bg station = "images/backgrounds/station.png"
image mira calm = "images/characters/mira_calm.png"
image mira smile = "images/characters/mira_smile.png"
```

Имя ресурса состоит из одного или нескольких слов через пробел.
Первое слово — **тег**. `mira calm` и `mira smile` занимают один слот персонажа,
поэтому смена эмоции не создаёт второго персонажа на экране.
Слова `at` и `with` зарезервированы и в имени ресурса не используются.

Фоны масштабируются с заполнением экрана и обрезкой лишних краёв.
Спрайты персонажей сохраняют пропорции и прозрачность; для них рекомендуется PNG.
Поддержка других форматов изображений определяется pygame/SDL_image.

### Реестр сцен и старт

```renpy
scene arrival = "scene/scene1.bne"
scene square = "scene/scene2.bne" mode novel
scene outro = "scene/scene3.bne" entry evening
start arrival
```

- Имя сцены — логический идентификатор, не имя файла.
- `mode novel` — текущий и единственный работающий режим.
- `entry` необязателен, по умолчанию `start`.
- `start` обязателен и объявляется один раз.
- `start outro.evening` позволяет явно указать входную метку.
- Режим `rpg` зарезервирован. Его подключение сейчас выдаёт понятную ошибку,
  а не запускает несуществующую ходьбу. `rpg.bne` в демо не зарегистрирован.

## 2. Сценарии `scene/*.bne`

Каждый сценарий состоит из меток. Внутри метки обязателен хотя бы один оператор.

```renpy
label start:
    "Начало сцены."
    jump meeting

label meeting:
    m "Привет!"
    return
```

Метки без явного перехода **продолжают выполнение в следующую метку того же файла**,
как в Ren’Py. Поэтому заканчивайте самостоятельные блоки `jump`, `return` или `end`.
На конце файла выполняется возврат к вызывающему `call`, а если его нет — конец истории.

### Реплики и подстановка

```renpy
"Реплика рассказчика без объявления персонажа."
n "То же самое через Character(None)."
m "Привет, [player_name]. Уровень доверия: [trust]."
p "Чтобы написать квадратные скобки: [[вот так]]."
```

Подстановка принимает только имя переменной, **не выражение**:
`[trust]` работает, `[trust + 1]` не вычисляется. Для расчёта используйте `$`.
`[[` и `]]` выводят буквальные скобки. Подстановка работает в именах и меню тоже.

Текст печатается постепенно; длинная реплика автоматически разбивается на страницы.
Переход к следующей команде происходит только после последней страницы.

### Фон и спрайты

```renpy
scene bg station with fade
show mira calm at right with dissolve
show mira smile with dissolve
hide mira with dissolve
```

- `scene имя` устанавливает фон **и удаляет все спрайты**.
- `show имя at позиция` добавляет персонажа или заменяет ресурс с тем же тегом.
- Позиции: `left`, `center`, `right`.
- Если `at` пропущено, сохраняется позиция существующего тега; новый тег появляется по центру.
- `hide тег` убирает спрайт. Писать имя эмоции после тега не нужно.
- У каждого оператора необязательное `with fade`, `with dissolve` или `with none`.
- `with fade` и `with dissolve` можно писать отдельной строкой после изменений сцены.

```renpy
window hide
pause 1.0
window show
```

`window hide` скрывает диалоговую панель, но не блокирует выполнение и не отключает ввод.
Если после него нужны реплики, верните `window show`. Меню выбора остаётся видимым.

### Переменные и выражения

```renpy
$ trust = 1
$ trust += 2
$ trust -= 1
$ trust *= 2
$ trust /= 2
$ trust //= 2
$ trust %= 3
$ has_key = True
$ player_name = "Лев"
```

Поддерживаются:

- `+`, `-`, `*`, `/`, `//`, `%`, скобки и унарные `+`, `-`;
- `==`, `!=`, `<`, `<=`, `>`, `>=`, включая `0 < trust <= 5`;
- `and`, `or`, `not`, с коротким замыканием;
- объединение строк через `+` и ограниченное повторение через `*`.

`%` предназначен только для чисел, не для форматирования строк.
Степень `**`, вызовы функций, индексы, атрибуты, `is`, `in`, коллекции и тернарное
выражение Python не поддерживаются. Выражение — до 2048 символов и 128 AST-узлов;
строка, в том числе после подстановки, — до 16 000 символов. Эти ограничения
предохраняют движок от случайно огромных вычислений и ресурсов.

### Условия

```renpy
if trust >= 3 and has_key:
    m "Ты готов."
elif trust > 0:
    m "Нужно найти ключ."
else:
    m "Для начала познакомимся."
```

Вложенные условия поддерживаются. Для пустой ветки используйте `pass`.
Максимальная вложенность — 32 уровня.

### Выборы

```renpy
m "Куда пойдём?"
menu:
    "На площадь":
        $ trust += 1
        jump square
    "Открыть дверь" if has_key:
        call open_door
    "Остаться здесь":
        pass

m "Выбор сделан."
```

- От 1 до 9 объявленных вариантов в одном `menu`.
- Вариант с ложным условием скрывается. Нумерация пересчитывается только для видимых вариантов.
- После выполнения ветки продолжается код **после всего меню**, если не было перехода.
- Если все варианты скрыты, движок сообщает об ошибке в строке `menu`.
- Длинное меню прокручивается колесом; клавиши `↑` / `↓` прокручивают к выделенному варианту.
- Заголовок выбора — обычная реплика перед `menu`, а не отдельная форма синтаксиса.

### Переходы и поддиалоги

```renpy
jump local_label
jump square
jump square.meeting

call help_dialogue
call square.meeting
return

end
```

Порядок разрешения неуточнённого имени:

1. Локальная метка текущего файла.
2. Зарегистрированная сцена и её входная метка.

Запись `сцена.метка` снимает неоднозначность. Целевые сцены и метки проверяются
заранее, даже если ветка пока недоступна.

`call` запоминает следующую команду и сцену. `return` возвращает туда управление.
При `return` **не откатываются** фон, спрайты или переменные.
Без активного вызова `return` заканчивает историю. `end` заканчивает её даже из
вложенного вызова. Цепочка вызовов ограничена 128 кадрами.

Движок также прерывает 10 000 команд подряд без диалога, выбора или `pause`:
это обычно означает случайный бесконечный `jump`.

### Пауза

```renpy
pause 0.8
pause
```

С числом — пауза в секундах; без числа — ожидание клика/клавиши.
Таймер не идёт, когда открыто меню паузы или история. Клик позволяет прервать паузу.

### Аудио

```renpy
play music "audio/evening.wav" loop fadein 1.2 volume 0.3
play music "audio/ending.ogg" noloop
play sound "audio/chime.wav" volume 0.5
stop music fadeout 1.0
stop sound
```

- Один музыкальный трек; эффекты могут накладываться друг на друга.
- Музыка по умолчанию зациклена. Для одноразового трека используйте `noloop`.
- `loop` / `noloop` поддерживаются только каналом `music`.
- `volume` — от 0 до 1; без него музыка использует `config.music_volume`, эффект — `1`.
- `fadein` / `fadeout` — от 0 до 30 секунд, по умолчанию `0`.
- `stop sound` останавливает все звуковые эффекты; `stop sound fadeout 1.0` тоже допустим.
- Рекомендуются WAV и OGG; остальные форматы зависят от SDL_mixer.
- Отсутствующее устройство или ошибка воспроизведения не блокируют чтение новеллы.

## 3. Проверка и диагностика

```bash
python -m bne game --check
```

Проверяются синтаксис, настройки, существование файлов, переменные,
персонажи, ресурсы, сцены и метки. Окно и аудиоустройство не требуются;
`--check` не импортирует pygame. Само декодирование изображений и звука
происходит при запуске: этот флаг не гарантирует корректность содержимого PNG/WAV.

Пример сообщения:

```text
game/scene/scene2.bne:18: Неизвестный персонаж «mirra».
```

Типы динамических вычислений, деление на ноль и отсутствие видимых вариантов
проверяются при выполнении соответствующей команды. Сценарий не может
исполнять произвольный Python или обращаться к файлам вне папки игры.
